# حزم نشر موقع العملاء (stoor)

**التاريخ:** 7 نوفمبر 2026

## الملفات

| الملف | الاستخدام |
|---|---|
| `stoor-client-standalone-2026-11-07.zip` | نسخة إنتاج جاهزة للتشغيل على أي استضافة Node — لا تحتاج `npm install` ولا بناء |
| `stoor-client-source-2026-11-07.zip` | نسخة المصدر الكاملة — للرفع إلى GitHub أو Vercel أو إعادة البناء على الخادم |

## التشغيل السريع (standalone)

1. فك الضغط على الخادم.
2. انسخ `.env.example` إلى `.env` واملأ القيم من `.env.local` في مشروعك المحلي.
3. شغّل:

```bash
# Linux / macOS
chmod +x start.sh
./start.sh

# Windows
start.cmd
```

4. الموقع يعمل على `http://<server>:3000`.

## Vercel

استخدم `stoor-client-source-2026-11-07.zip` (أو ارفعه إلى GitHub) واتبع `DEPLOY.md` داخل الحزمة.

## ملاحظات مهمة

- ملفات البيئة السرّية **غير مضمّنة** في أي من الحزمتين.
- `.env.example` يحتوي أسماء المتغيرات فقط + مفتاح anon العام.
- بعد النشر، حدّث `STORE_URL` و`STORE_REVALIDATE_URL` في لوحة المدير لتشير إلى الدومين العام.
- اسم المتجر الحالي في قاعدة البيانات هو «الشجاع» — عدّله من «معلومات المتجر» إن لزم قبل الإطلاق.
