## أين أدار كل شيء الآن؟

| المهمة | المكان |
|---|---|
| الدخول | تطبيق «مدير» — `http://127.0.0.1:4100` |
| الطلبات ومراجعة إيصالات التحويل | تطبيق «مدير» → الطلبات |
| المنتجات (بألوان ومخزون لكل لون + صور) | تطبيق «مدير» → المنتجات |
| التصنيفات وروابطها | تطبيق «مدير» → التصنيفات |
| بيانات الحساب البنكي والمحافظ | تطبيق «مدير» → الدفع والمحافظ |
| معلومات المتجر (الاسم، الوصف، الترحيب، التواصل، الشعار) | تطبيق «مدير» → معلومات المتجر |

## ما أُزيل من المتجر

- صفحات `/admin/*`.
- مسارات `/api/admin/*` (المنتجات، الإعدادات، الإيصالات، الجلسة).
- صفحة `/login` الإدارية ومكوّناتها.
- جلسة المدير داخل المتجر (`stoor_admin`) و`lib/auth.ts` و`lib/admin.ts`.

مصادقة العميل في `/account` مستقلة تماماً وبقيت كما هي (`stoor_customer` بمفتاح `SESSION_SECRET`).
