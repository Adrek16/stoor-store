# تحليل موقع JOJ Accessories
### تقرير فني شامل لبناء متجر مشابه بـ Next.js

**المصدر:** https://joj-accessories.com/ar
**تاريخ التحليل:** 1 نوفمبر 2026
**نوع الموقع:** متجر إلكتروني (Salla) — إكسسوارات نسائية
**السوق:** السعودية — العملة: ريال سعودي (SAR)

> **تنبيه:** هذا تحليل للموقع **المرجعي** فقط. متجرنا يمني (ريال يمني، بلا شحن ولا كوبونات ولا تغليف).  
> الخطة التنفيذية المعتمدة في [`customer-screens-plan.md`](./customer-screens-plan.md).

## 1. البصمة التقنية (Tech Stack)

| العنصر | القيمة |
|---|---|
| المنصة | Salla (منصة سعودية جاهزة) |
| الثيم | `581928698` الإصدار `1.228.0` |
| مكتبة الواجهة | Twilight.js 3.0.18 + Web Components |
| الخط | **Cairo** من Google Fonts |
| الصور | WebP عبر CDN مع `fit=scale-down` |
| الحماية | Cloudflare + Rocket Loader |
| اللغة | عربي فقط (`/ar`)، RTL كامل |

> **الخلاصة:** الموقع مبني على قوالب Salla الجاهزة، وليس تطويراً مخصصاً. هذا يعني أن أداءه محدود بالمنصة، ونحن سنتجاوزه بـ Next.js (SSR/ISR + صور محسّنة).

## 3. الهيكل الكامل للصفحة الرئيسية (بالترتيب)

```
1. شريط إعلان متحرك (Marquee)
   "شحن مجاني للطلبات فوق 499 ريال | خصم 10% بكود JOJ"
   → مكرر 15 مرة لضمان حركة سلسة بدون فراغ

2. الهيدر (centered_logo)
   ├─ شريط علوي: نبذة عنا · اراء العملاء · دليل العناية | العربية 🌐
   ├─ الشعار في المنتصف + بحث + حساب + سلة
   └─ قائمة التصنيفات: اطقم · سلاسل · خواتم · أقراط · أساور · خلاخيل

3. Hero Banner
   صورة عريضة + "اكسسوارات جوج | بريق الذهب الذي يدوم"

4. شبكة التصنيفات (6 مربعات)
   أيقونة + اسم عربي + اسم إنجليزي

5. أقسام مجموعات المنتجات (متكررة × 6)
   ├─ عنوان القسم + "عرض الكل"
   ├─ صف منتجات (سعر، تقييم، زر إضافة سريع)
   └─ بانر ترويجي بين الأقسام

6. آراء العملاء (شبكة 8+ بطاقات)
   صورة + اسم + نص + نجوم

7. زر واتساب عائم "اطلب واتساب"

8. الفوتر
   ├─ منحنى SVG
   ├─ عمود روابط مهمة (6 روابط)
   ├─ الشعار + وصف العلامة في المنتصف
   └─ عمود تواصل/سياسات
```

## 4. أنماط التجارة الإلكترونية المستخدمة

| النمط | التفاصيل | يستحق التقليد؟ |
|---|---|---|
| شريط متحرك | يخلق إحساساً بالحركة والحيوية | ✅ |
| شعار في المنتصف | يمنح طابع «بوتيك» راقٍ | ✅ |
| الطلب عبر واتساب | قناة تحويل أساسية في الخليج | ✅ **ضروري** |
| عتبة شحن مجاني | 499 ريال (يرفع متوسط السلة) | ❌ **لا يناسبنا — لا شحن** |
| كود خصم | `JOJ` بنسبة 10% | ❌ **لا يناسبنا — لا كوبونات** |
| آراء العملاء | 8 بطاقات بأسماء حقيقية | ✅ (مرتبطة بتقييمات معتمدة) |
| تصنيف ثنائي اللغة | "سلاسل-necklaces" | ⚠️ مشوّش — نستخدم عربي فقط |
| بانرات فارغة | `s-empty-wide.png` في 4 مواضع | ❌ **عيب واضح** |

### نقاط ضعف الموقع الحالي (فرصتنا)

1. **بانرات ترويجية فارغة** — 4 مواضع تعرض صورة placeholder.
2. **لا يوجد نسخة إنجليزية** — يقيّد الجمهور.
3. **لا فلاتر حقيقية** في صفحات التصنيف (المنتجات تُحمّل بـ JS).
4. **بطء محتمل** — Rocket Loader + Web Components + خطوط خارجية.
5. **لا نظام مقاسات/ألوان واضح** للمنتجات.
6. **لا بحث ذكي** ولا اقتراحات.
7. **صفحة منتج ضعيفة** — لا هرم نوتات عطرية ولا مكونات.

## 5. خطة متجرنا (عطور + إكسسوارات، رجالي ونسائي)

### لماذا نتجاوز النموذج الأصلي
الموقع الأصلي **نسائي فقط**. متجرنا يضيف **العطور** و**القسم الرجالي**، وهذا يتطلب:

- تصنيف ثنائي المستوى: **الجنس → النوع**
- بطاقة منتج تدعم: عطر (حجم ml) / إكسسوار (لون، مقاس)
- هرم النوتات العطرية في صفحة المنتج (Top / Heart / Base)
- فلترة بالمُصنَّع (رجالي / نسائي / مشترك)

### شجرة التصنيفات

```
عطور
├─ عطور رجالية      men-perfumes
├─ عطور نسائية      women-perfumes
└─ عطور مشتركة      unisex-perfumes

إكسسوارات
├─ نسائية
│  ├─ سلاسل         necklaces
│  ├─ أقراط         earrings
│  ├─ أساور         bracelets
│  ├─ خواتم         rings
│  └─ أطقم          sets
└─ رجالية
   ├─ ساعات         watches
   ├─ أساور جلدية   leather-bracelets
   ├─ سلاسل رجالية  men-necklaces
   └─ أزرار أكمام   cufflinks
```

## 6. المعمارية التقنية المقترحة

### المكدّس
| الطبقة | التقنية |
|---|---|
| الإطار | **Next.js 16** (App Router) |
| اللغة | **TypeScript** |
| التنسيق | **Tailwind CSS v4** |
| الخطوط | `next/font` (Cairo) — تحميل محلي، بدون CLS |
| الحالة | React Context — *الخطة:* سلة على الخادم لكل عميل مسجّل بدل `localStorage` |
| البيانات | طبقة بيانات معزولة (`lib/products.ts`) → قابلة للاستبدال بـ Supabase/Medusa |

### لماذا هذا التقسيم
طبقة البيانات معزولة عمداً: اليوم ملفات TS، وغداً قاعدة بيانات حقيقية — دون لمس الواجهة.

### خريطة المسارات
```
/                        الرئيسية
/category/[slug]         تصنيف + فلاتر
/product/[slug]          صفحة منتج
/cart                    السلة
/search?q=               البحث
```

### الأداء المستهدف
- Lighthouse ≥ 95
- LCP < 1.5s (صور محسّنة + `priority` للـ hero)
- صفر تحميل خطوط خارجية (self-hosted)
